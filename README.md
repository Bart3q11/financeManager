# Finance Manager 
Aplikacja do zarządzania finansami osobistymi: konta, przychody, wydatki, budżet i raporty.

## Autorzy
- Bartosz Derda 
- Dominik Matczak 

##  Wymagania funkcjonalne

- [ ] Zakładanie kont (gotówka, bankowe, oszczędnościowe) 
- [ ] Dodawanie przychodów 
- [ ] Dodawanie wydatków 
- [ ] Przelewy między kontami 
- [ ] Edycja i usuwanie transakcji 
- [ ] Historia transakcji
- [ ] Saldo kont i saldo łączne 
- [ ] Kategorie wydatków 
- [ ] Zapis i odczyt danych z pliku 
- [ ] Walidacja danych i obsługa błędów
